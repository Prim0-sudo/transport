# Miniature World activity tiles · first artwork review

The user selected the Plants-style activity compositions in Transport’s Miniature World style and requested these three finished illustrations before the rest. The [preview board](review.html) uses the actual transparent originals and shows cream tile placement at desktop and phone scale, plus a navy edge check. It is an asset review, with no changes to the learner menu.

| Menu mode | Original | Readable cue |
|---|---|---|
| learn | meet-the-words.png | An open travel field guide with bus, ferry and airplane illustrations. |
| detective | transport-detective.png | A brass magnifier reveals a partly covered locomotive clue. |
| wheel | spin-the-wheel.png | A tabletop spinner with five vehicle wedges, a fixed gold pointer and a wooden base. |

The PNGs retain their generated alpha. The [ledger](manifest.json) records exact prompts, source hashes and measured visible bounds. Use those bounds for placement and preserve the full subject and aspect ratio. Titles remain native menu text. The art references the proportions and activity cues in Plants, with new Transport subjects and a shared navy, cream, brass and teal palette. See the [menu artwork brief](../../../docs/TRANSPORT-MENU-ART-BRIEF.md) for the later tile list.
